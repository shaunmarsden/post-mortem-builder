# Worked Example

Four entirely fictional cases, a rejected job application, a paused grant, a quiet partnership pitch, and an unconditional decline, built to test whether the classifications actually hold apart from each other.

- [cases.md](cases.md): the four cases as given
- [output.md](output.md): the post-mortem [SKILL.md](../SKILL.md) produces for each
- [review.md](review.md): whether each was told apart from the others, particularly the no-decision case, which is not a rejection at all, and the unconditional decline, which should never be softened into a reason to try again
