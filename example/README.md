# Worked Example

Four fictional cases: a rejected job application, a paused grant, a quiet partnership pitch and an unconditional decline. They test whether the classifications stay distinct from each other.

- [cases.md](cases.md): the four cases as given
- [output.md](output.md): the post-mortem [SKILL.md](../SKILL.md) produced for each
- [review.md](review.md): whether each was told apart from the others, especially the no-decision case, which isn't a rejection at all, and the unconditional decline, which should never be softened into a reason to try again
