# Human Review Checklist

Run through this before deciding whether to try again.

- [ ] The classification is based on what was actually said, not a story that would make the most sense of it
- [ ] A blended reason was not collapsed into one tidy factor; multiple stated causes were kept visibly separate if none was confirmed as primary
- [ ] A genuine no-decision was not mistaken for a rejection, or vice versa
- [ ] No reason to try again was invented where the evidence only supports an unknown
- [ ] An unconditional decline was respected, not softened into a reason to try a different angle
